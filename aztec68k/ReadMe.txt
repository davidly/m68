ReadMe for Aztec68K

Manx Axtec C68K MS-DOS based Cross Development Software for 
Motorola 68000-based Systems

Aztec C68K 3.6b Rom 6-6-88  
Copyright 1982-88 Manx Software Systems, Inc.
Aztec 680X0 Assembler 3.6B 6-9-88

Set-up, libraries built, and rebundled for Windows XP, but should work
just fine in any MS-DOS environment or emulator. Unzip and you should be
good to go.

I have no documentation for this compiler and it is apparently entirely
console based. Any documentation you can provide would be appreciated.

Read the library listings and readme in the DOCS directory and see the
sample an makefile in the samples directory and the libray source for
more details.

This comes with complete source code.
